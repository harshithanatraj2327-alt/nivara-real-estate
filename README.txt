NIVARA REAL ESTATE WEBSITE
==========================

Files:
- index.html: page structure and demo property listings
- style.css: responsive styling
- script.js: mobile menu, search filters, favourites and demo details

HOW TO RUN:
1. Extract the ZIP folder.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html.
4. Recommended: install the VS Code extension "Live Server", right-click index.html and choose "Open with Live Server".

IMPORTANT:
- This is a front-end demo with sample property listings.
- Property photos and Google Fonts load from the internet, so an internet connection is needed for those assets.
- The search/favourite features work on the sample cards only.
- The contact email/phone are demo details; replace them with your own before publishing.
- The property details buttons show a demo message. A real listing database and enquiry backend are not connected.
- This project recreates the general visual layout and styling shown in your reference screenshots; it is not the original NIVARA source code.
